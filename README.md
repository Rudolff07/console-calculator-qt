# Console Calculator (Qt)

Лабораторная работа №1 по Qt: консольный калькулятор с использованием
метаобъектной системы, сигналов и слотов.

## Вариант

Средний уровень, вариант 7: **калькулятор с отменой (undo)**.

## Что умеет

- Арифметические операции: `add`, `sub`, `mul`, `div`
- Отмена последней операции: `undo`
- Сброс состояния: `reset`
- Справка: `help`
- Выход: `quit`
- Обработка ошибок: деление на ноль, неверный формат ввода
- Запись истории успешных операций в `history.txt` (демонстрация
  принципа «один сигнал → несколько слотов»)

## Требования

- Qt 6.x (модуль QtCore)
- Компилятор C++17 (Clang на macOS, GCC на Linux, MSVC/MinGW на Windows)
- qmake

## Сборка и запуск

### Через Qt Creator

1. Открыть `lab1.pro`.
2. Собрать проект (`⌘ + B`).
3. Запустить (`⌘ + R`).

### Через командную строку

```bash
qmake lab1.pro
make
./lab1
